# WHAT ARE TIME AND SPACE COMPLEXITIES?

Time complexity helps us to understand the relationship between the runtime (number of operations) and the input size of an algorithm.

Space complexity helps us to understand the relationship between the memory usage and the input size of an algorithm.

Both are expressed with Big O(worst case) notation. Best to worst time complexity (n: input number): Constant Time O(1), Logarithmic Time O(log n), Linear Time O(n), Quadratic Time O(n^2), Exponential Time O(2^n), etc… 

We choose the best solution for our problem by considering the time and space complexity of algorithms so that we can write more efficient programs.
