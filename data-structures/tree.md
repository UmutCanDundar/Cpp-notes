# TREE - class

Consists of nodes having value and pointing (left, right) nodes(children) - (binary tree)
Can be Full (each node points to either 0 or 2 nodes),
	Perfect (all levels completely filled),
	Complete (filled from left to right)
The top node is called root, a node that does not have any child is called leaf
Binary Search Tree: Right child is grater, left is lower
		            Can’t have duplicate elements
Lookup, Insert, Remove – O(log n) 
(In the worst case, binary search tree treats as linked-list - O(n))
Space Complexity – O(n)
